# Photos

All photos are the client's own work, delivered on 2026-11-01 as camera originals and
phone shots, sorted into one folder per project plus a folder of other gallery photos.
The folders were named after the client's customers, so those names are kept out of
the repository: files are named after the project (`<id>-NN.jpg`) or `g-NN.jpg` for the
home page photo wall, and only the original file name is recorded below.

Every photo was converted the same way (sharp, see `CLAUDE.md`): upright (EXIF rotation
applied), sRGB, at most 2400px on the long side, mozjpeg quality 80, all metadata (GPS
included) stripped. `<id>-video.jpg` is the first frame of the project's clip in
`public/video/`, used as its poster. `unused/` holds wall photos left out so every filter
view packs; `archive/` holds the previous site's photos.
